# Видеоуроки для 1С

Программа собирает готовый ролик по теме в «1С:Бухгалтерии»: сценарий, шаги по экрану, кадры, голос, субтитры, рамки со стрелками, заставку «Урок: …» и концовку.

1С стоит на вашем компьютере с Windows, не в облаке Cursor. Здесь можно проверить весь путь на макете (нарисованные экраны). Настоящую базу программа нажимает только у вас, и только если вы сами подтвердили, что это учебная копия.

## Что уже получается

- Тема вроде «как учесть входной НДС при УСН». Если свой сценарий не приложен, программа пишет его по карточке источников.
- Карточка даёт ссылки на [v8.1c.ru/buhv8](https://v8.1c.ru/buhv8/) и портал [1С:ИТС](https://its.1c.ru/). Полный текст ИТС в проект не копируется: он по подписке.
- Свои заметки можно приложить файлом.
- Шаги раскладываются на кнопки и поля.
- На макете (и на вашем Windows — со снимка окна 1С) собирается mp4: голос, файл субтитров, оранжевая рамка, стрелка, заставка и концовка.
- Отправка отчётов в ФНС и платежи в сценарий не попадают: такой шаг сборка отвергает.

Учебный пример в ролике: бумага офисная, 10 штук по 244 ₽, всего 2 440 ₽, в том числе НДС 440 ₽. Ожидаемая проводка в макете — дебет 10.01, кредит 60.01. В вашей базе счёт может быть другим. Перед публикацией откройте движения документа.

## Чего эта версия ещё не делает

- Не скачивает ИТС и не подключается к вашей базе из Cursor.
- Готовая карточка шагов есть для входного НДС при УСН. Другая тема станет черновиком: ролик соберётся, но подписи кнопок надо вписать самим.
- Готовый ролик склеен из кадра на каждый шаг, а не из непрерывной записи с вырезанием пауз. Непрерывная запись `raw-screen.mp4` на Windows сохраняется рядом, если установлен ffmpeg, но в монтаж урока пока не режется.
- Встроенный голос механический. Для нормальной речи нужен Edge или ElevenLabs.
- Живая 1С в этой среде не проверялась. На Windows сначала сделайте пробный проход без нажатий.

## Шаг 1. Что поставить на Windows

1. Python 3.11 или новее с сайта python.org. Галочка «Add python to PATH» удобна, но не обязательна: на Windows часто работает только команда `py -3`. Файлы `Собрать учебный урок.cmd` и `Записать урок в 1С.cmd` сначала пробуют `py -3`, и только если лаунчера нет — `python`.
2. В папке проекта откройте PowerShell. Если `python` не находится, в командах ниже пишите `py -3` вместо `python`. Пример: `py -3 -m pip install -r requirements.txt`. Дальше в тексте для краткости написано `python`.

```powershell
python -m pip install -r requirements.txt
```

3. ffmpeg. Проверка: в PowerShell команда `ffmpeg -version` печатает номер версии. Если команды нет, установите ffmpeg и снова откройте PowerShell. Без ffmpeg ролик не соберётся.
4. Учебная копия базы «1С:Бухгалтерия предприятия 3.0». Рабочую базу для этого не открывайте: сценарий создаёт документ и проводит его.
5. Ключи в код не кладите.
   - Встроенный голос и макет ключей не требуют.
   - Голос Edge: `python -m pip install edge-tts`. Ключ не нужен, нужен интернет. Текст сценария уходит в сервис Microsoft. Запись экрана и база туда не отправляются.
   - Голос ElevenLabs: двойной щелчок по `Подключить ElevenLabs.cmd`. Ключ попадёт только в файл `.env` на вашем компьютере. Этот файл в Git не входит.

## Шаг 2. Собрать учебный ролик без 1С

Двойной щелчок по файлу `Собрать учебный урок.cmd`.

Либо в PowerShell из папки проекта:

```powershell
python -m pipeline run
```

Готовый файл: `artifacts\lessons\…\lesson.mp4`. Рядом будут `subtitles.srt` (субтитры), `script.json` (текст) и `plan.json` (шаги). В кадре написано «Макет интерфейса»: это не запись вашей базы. Голос по умолчанию встроенный.

Проверка для тех, кто запускает тесты:

```powershell
python -m unittest discover -s tests
```

## Шаг 3. Свой запрос

Скопируйте `fixtures\vat-usn\request.json` в свой файл, например `мой-урок.json`, и поправьте тему. Запуск:

```powershell
python -m pipeline run --request мой-урок.json
```

Свои заметки — обычный текстовый файл. В команде:

```powershell
python -m pipeline run --topic "Как учесть входной НДС при УСН" --configuration "Бухгалтерия предприятия, редакция 3.0" --materials заметки.txt
```

Если сценарий уже написан, передайте JSON с полями `intro_narration`, `outro_narration` и `scenes`. У каждого шага есть `action` (`click`, `set_text`, `check` или `focus`), `target` и `caption`. Пример структуры лежит в `fixtures\vat-usn\lesson.json`. Запуск: `--script мой-сценарий.json`.

Подписи кнопок для макета — в `fixtures\vat-usn\ui-map.json`, поле `name`. Для живой 1С программа ищет на экране именно эту подпись.

## Шаг 4. Пробный проход по живой учебной базе

1. Откройте учебную базу сами. Оставьте одно окно 1С на начальной странице. Лишние окна 1С закройте.
2. Узнайте реальные подписи:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Inspect-1C.ps1
```

Отчёт `artifacts\ui-probe.json` может содержать названия организаций. Не выкладывайте его. Если нужной подписи в плане нет, впишите её в `plan.json` в поле `automation_name` (файл появится после первой сборки) или в `name` внутри `ui-map.json`. Частая причина остановки: в базе написано «Контрагент:» с двоеточием, а в плане без него. Кнопка движений в части релизов называется не «Дт Кт», а «Показать проводки».
3. Пробный проход ничего не нажимает и не вводит текст, только ищет элементы и снимает окно:

```powershell
python -m pipeline run --driver windows --confirm-training-copy --dry-run --tts offline
```

Флаг `--confirm-training-copy` ставьте только для учебной копии.

## Шаг 5. Запись урока в учебной базе

Двойной щелчок по `Записать урок в 1С.cmd`. Программа спросит подтверждение: введите латинскими буквами `YES`. Так сделано специально, чтобы слово не ломалось из‑за кодировки окна.

Либо:

```powershell
python -m pipeline run --driver windows --confirm-training-copy --tts auto
```

`--tts auto` берёт Edge, если пакет `edge-tts` установлен и сервис ответил. Иначе включается встроенный голос. Чтобы выбрать голос явно:

```powershell
python -m pipeline run --driver windows --confirm-training-copy --tts edge --voice ru-RU-DmitryNeural
```

Мужские голоса, которые уже одобрены в студии: `fr-FR-RemyMultilingualNeural` (Реми) и `de-DE-FlorianMultilingualNeural` (Флориан). Для ElevenLabs: `--tts elevenlabs` и идентификатор голоса, например Лили. Ключ берётся из `.env`, в командную строку его не подставляйте.

Во время прохода не переключайте окна. Если шаг не найден или проверка «на экране не то значение» не сошлась, ролик не считается готовым. Текст ошибки будет на экране. Исправьте подпись или учебные данные и запустите снова.

Несколько окон 1С: добавьте `--process-id` и номер процесса из диспетчера задач.

## Запись в реальной 1С

Нужна открытая учебная база «Бухгалтерия предприятия 3.0», интерфейс «Такси», организация «Альфа ООО». Рабочую базу не открывайте. Окно 1С одно. Лишние окна закройте.

Программа ищет разделы слева так, как они подписаны на главном окне: Главное, Банк и касса, Покупки, Справочники и остальные. Перед щелчком она ведёт курсор и показывает рамку. Диктор читает шаг (голос Edge, если пакет `edge-tts` установлен; иначе встроенный голос). Пояснение «почему так» попадает в субтитры. Заставка и концовка — с заголовком «Урок …». Экран пишется через ffmpeg (`gdigrab`). Кнопки «Отправить», «Выгрузить» и «Удалить» не нажимаются. Остановка — клавиша Esc.

«Создать» и «Провести» нажимаются только в режиме записи и только в тех шагах, где это прямо сказано. Суммы и даты диктор проговаривает. Ввод в конкретное поле включается, если в шаге YAML есть список `fields` с именем поля и значением: так случайная цифра не попадёт не в то поле.

Шаг 1. Один раз поставьте пакет для управления окном:

```powershell
py -3 -m pip install -r requirements.txt
```

Шаг 2. Проверка кода ТН ВЭД у номенклатуры «Смартфон» (только чтение):

```powershell
py -3 -m pipeline tnved --confirm-training-copy --out "artifacts\tnved-report.json"
```

Тот же запуск двойным щелчком: `Проверить ТН ВЭД.cmd`. Если код не `8517 13 000 0`, программа предупредит, что ставка сбора 73 860 ₽ по ПП РФ № 1637 может не подойти. Если карточки «Смартфон» нет, проверка так и напишет и завершится без ошибки: запись урока создаст её с кодом `8517 13 000 0`. Повторяющиеся подписи вроде «НДС» пробный прогон не останавливают: выбирается поле в текущей форме, а файл `dry-run.json` пишется всегда.

Шаг 3. Пробный прогон урока 1. Он только ищет подписи в текущем окне, ничего не проводит и не записывает:

```powershell
py -3 -m pipeline live --lesson "lessons\lesson1.yaml" --dry-run --confirm-training-copy --out "artifacts\lessons\lesson1-dry"
```

Или файл `Пробный прогон урока 1.cmd`. Отчёт `dry-run.json`: что найдено и чего на экране нет. Начальная страница содержит разделы, но не поля будущего документа — это нормально, такие строки будут в списке «Нет на экране».

Если команда остановилась, в той же папке будут `screen.png` и `ui-dump.json`. Снять дерево окна отдельно:

```powershell
py -3 -m pipeline dump-ui --confirm-training-copy --out "artifacts\ui-dump.json"
```

В начале и в конце проверки ТН ВЭД, пробного прогона и записи программа закрывает открытую панель клавишей Esc и возвращается на вкладку «Начальная страница». Если вкладка не читается, она нажимает левый верх окна, как на вашем экране 1920×1080.

Пути разделов записаны заранее в `pipeline/bp30_ui_map.yaml` по открытой документации полного интерфейса «Такси» (ИТС, БУХ.1С, v8.1c.ru). Запись сначала ищет точное имя из этой карты, затем запасное название релиза, и только потом общий поиск. Карта не заменяет выгрузку конфигурации: где имя группы панели в статье не процитировано, у пункта стоит пометка средней или низкой уверенности.

Шаг 4. Запись урока 1, когда пробный прогон вас устроил:

```powershell
py -3 -m pipeline live --lesson "lessons\lesson1.yaml" --confirm-training-copy --tts auto --out "artifacts\lessons\lesson1"
```

Или `Записать урок 1 в 1С.cmd` и ответ `YES`. Готовый файл: `artifacts\lessons\lesson1\lesson.mp4`. Рядом `subtitles.srt` и `raw-screen.mp4`.

Уроки 2 и 3 запускаются так же, с файлами `lessons\lesson2.yaml` и `lessons\lesson3.yaml`. В текстах диктора и в поле `legal_note` («почему так») сохранены формулировки сценария.

## Что лежит в папке урока

| Файл | Зачем |
| --- | --- |
| `lesson.mp4` | Готовый ролик |
| `subtitles.srt` | Субтитры |
| `script.json` | Текст, который можно поправить и подать снова через `--script` |
| `plan.json` | Шаги и подписи для 1С |
| `journal.json` | Что исполнитель реально нашёл на экране |
| `video-result.json` | Итог: длительность, голос, пометка «нужно проверить» |
| `raw-screen.mp4` | Непрерывная запись окна, если на Windows нашёлся ffmpeg |

Слово «кредит» в проводках для голоса произносится как «кре́дит» (ударение на первый слог). На экране и в субтитрах написание обычное. Правило лежит в `config\pronunciation.json`.

## Если сборка остановилась

- «python не найден» — переустановите Python с галочкой Add to PATH и откройте PowerShell заново.
- «ffmpeg не собрал фрагмент» — установите ffmpeg.
- «Окно 1С не найдено» — база должна быть открыта в этом же сеансе Windows.
- «Не найден элемент» — подпись в плане не совпала с экраном. Возьмите имя из `ui-probe.json`.
- «Проверка не сошлась» — в базе другая система налогообложения, другая ставка или другие проводки. Для УСН «доходы минус расходы» и включённого «НДС включать в стоимость» пример ждёт сумму 2 440 на счёте учёта номенклатуры. Если политика другая, поправьте сценарий, не публикуйте макет как факт.
- Голос Edge не ответил — повторите позже или соберите с `--tts offline`. Уже озвученные куски лежат в папке `voice` и при том же тексте берутся из кэша.

Старые кнопки студии (`Открыть студию 1С.cmd`) по-прежнему только проверяют доступ к окну, фокус и короткую демонстрацию. Целый урок запускается командами выше.

## Произношение

Справочник: `config/pronunciation.json`. В бухгалтерских проводках
«кредит» озвучивается как «кре́дит», с ударением на первый слог.
Правило применяется к целому слову с сохранением регистра перед отправкой
текста в ElevenLabs или Edge TTS. Текст сценария и экранные подписи не меняются.
Кэш учитывает исправленный текст: при следующей сборке переозвучиваются
только затронутые фрагменты. Уже готовое видео автоматически не изменяется.

## Настройки .env

Файл `.env` в корне проекта содержит ключ ElevenLabs, модель и копию основных
настроек проекта. Генератор ElevenLabs читает ключ и модель из `.env`;
сценарий и `config/*.json` остаются источником настроек урока и выбора голоса.
Ключ вводится через «Подключить ElevenLabs.cmd» и сохраняется только в
локальном `.env`. Файл исключён из Git; после клонирования проекта его нужно
создать на своём компьютере. Ключи других сервисов не требуются.

## Выбор голоса

По оценке пользователя для русского текста предпочтительны мужские голоса
Реми (`fr-FR-RemyMultilingualNeural`) и Флориан (`de-DE-FlorianMultilingualNeural`).
Они сохранены в `config/voices.json`. В студии выберите голос в списке
«Голос следующей озвучки» и нажмите «Сохранить голос».
Выбор меняет сценарий следующей сборки, не запускает синтез и не пересобирает
готовое видео. Аудиокэш хранится отдельно для каждого голоса.
Реми установлен начальным значением; оба предпочтительных голоса доступны.
Из женских голосов пользователь одобрил Талиту
(`pt-BR-ThalitaMultilingualNeural`): она также доступна в списке выбора.
Остальные женские голоса остаются кандидатами и в список не включены.
Также одобрены Лили (`pFZP5JQG7iQjIQuC4Bku`) и Сара
(`EXAVITQu4vr4xnSDxMaL`) из ElevenLabs. Они доступны в том же списке.
При выборе сохраняется соответствующий провайдер; сборка ElevenLabs читает
ключ из `.env`. Сохранение выбора не запускает синтез и не расходует кредиты.
Их пробы: `artifacts/voice-tests-female`; повторная генерация —
`tools/make_voice_tests.py --female`. Все пробы звучат без ускорения.

## Требования к следующим урокам

В первые секунды обязательно звучит вступление: что зритель научится делать,
в какой программе и с какого раздела начинаем. Далее показывается создание
документа с пустой формы. Озвучка — мужская, с разговорными формулировками;
ожидания между действиями удаляются, итоговые видео и звук ускоряются в 1,1 раза.

Новая версия сценария подготовлена в `scenarios/books-creation-video.json`.
Для неё выбран нейросетевой голос ru-RU-DmitryNeural. Сборка новой версии
остановлена из-за повторяющихся ошибок Microsoft Edge TTS на последних
двух фрагментах. Пользователь разрешил передачу текста сценария этому сервису.
Семь из девяти фрагментов готовы; повторный запуск использует их кэш.
Образец вступления: `artifacts/books-creation/neural-voice/intro-preview-1.1x.mp3`.

## Проверка доступности интерфейса

Откройте учебную базу в обычном сеансе Windows, затем выполните в корне проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Inspect-1C.ps1
```

При нескольких открытых базах можно указать `-TargetProcessId <PID>`.
Параметр ExecutionPolicy применяется только к этому процессу PowerShell;
постоянная политика Windows не меняется.
Скрипт только читает дерево Windows UI Automation: подписи, типы,
координаты и доступные шаблоны действий. Он не нажимает кнопки,
не вводит данные, не запускает и не изменяет базы.
Отчёт сохраняется в `artifacts/ui-probe.json` и может содержать видимые
названия организаций и документов. Не публикуйте его без просмотра.

`no_visible_1c_window` означает, что в доступном сеансе не найдено окно 1С;
это не доказывает отсутствие поддержки автоматизации.
`inspection_complete` означает завершение сбора дерева, а не подтверждение
пригодности всех полей. Ошибки и ограничения обхода указаны в отчёте.

Следующий этап — оценить дерево на форме документа и выбрать исполнитель:
Windows UI Automation либо отдельный адаптер тестирования платформы 1С.
Совместимость второго варианта пока не проверена. Внутренние имена из
старого `.feature` нельзя считать идентификаторами Windows UI Automation.

После выбора исполнителя нужны проверяемые шаги с ожидаемым результатом,
журнал событий и координат для монтажа, запись экрана, озвучка и аннотации.
Эти части пока не реализованы. Пробный и чистовой проходы должны начинаться
с одного состояния учебной копии базы.

## Проверка фокуса без изменения документа

Пользователь подтвердил, что работает с учебной копией.
Откройте один документ поступления и запустите двойным щелчком
`Проверить управление 1С.cmd`. Скрипт ищет одно доступное поле
«Комментарий:», читает его значение, ставит фокус и проверяет, что
фокус подтверждён, а значение осталось прежним. Текст не вводится,
кнопки записи и проведения не нажимаются. При нескольких подходящих
полях скрипт останавливается. Результат: `artifacts/focus-test.json`.
Не вводите текст в 1С во время короткой проверки.

## Окно приложения

Запустите `Открыть студию 1С.cmd` двойным щелчком. Откроется окно
с двумя кнопками: проверка доступности интерфейса и проверка фокуса.
Каждая проверка выполняется в отдельном процессе в вашем сеансе Windows;
таймаут 45 секунд. Результат показан простым текстом и сохранён в artifacts.
Доступность окон из сеанса разработки может отличаться от доступности
в вашем интерактивном сеансе. Приложение пока выполняет только диагностику.

## Демонстрационная запись

Кнопка «3. Записать демонстрацию» переключает фокус между полями «Номер»,
«Контрагент» и «Комментарий» существующего документа. Перед записью все
три поля должны быть найдены однозначно. Значения проверяются до и после.
Студия сворачивается на время записи и возвращается после завершения.
Не переключайте окна и не вводите данные во время прохода.

Сохраняются видео `artifacts/demo-<дата-время>.avi` и журнал
`artifacts/demo-result.json`. Записывается весь монитор с выбранным полем,
поэтому уберите с него посторонние окна. Рамки и пояснения добавляются
непосредственно в кадры. Формат Motion JPEG AVI, 6 кадров/секунду,
12 секунд видео без аудио; при медленном захвате реальный проход длиннее.
При ошибке частичный видеофайл не считается успешным результатом.
Это демонстрация фокуса, а не заполнение документа или декларации.
