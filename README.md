## Произношение

Справочник: `config/pronunciation.json`. В бухгалтерских проводках
«кредит» озвучивается как «кре́дит», с ударением на первый слог.
Правило применяется к целому слову с сохранением регистра перед отправкой
текста в ElevenLabs или Edge TTS. Текст сценария и экранные подписи не меняются.
Кэш учитывает исправленный текст: при следующей сборке переозвучиваются
только затронутые фрагменты. Уже готовое видео автоматически не изменяется.

## Настройки .env

Файл `.env` в корне проекта содержит ключ ElevenLabs, модель и копию основных
настроек проекта. Генератор ElevenLabs читает ключ и модель из `.env`;
сценарий и `config/*.json` остаются источником настроек урока и выбора голоса.
Ключ вводится через «Подключить ElevenLabs.cmd» и сохраняется только в
локальном `.env`. Файл исключён из Git; после клонирования проекта его нужно
создать на своём компьютере. Ключи других сервисов не требуются.

## Проверка доступности интерфейса

Откройте учебную базу в обычном сеансе Windows, затем выполните в корне проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Inspect-1C.ps1
```

При нескольких открытых базах можно указать `-TargetProcessId <PID>`.
Параметр ExecutionPolicy применяется только к этому процессу PowerShell;
постоянная политика Windows не меняется.
Скрипт только читает дерево Windows UI Automation: подписи, типы,
координаты и доступные шаблоны действий. Он не нажимает кнопки,
не вводит данные, не запускает и не изменяет базы.
Отчёт сохраняется в `artifacts/ui-probe.json` и может содержать видимые
названия организаций и документов. Не публикуйте его без просмотра.

`no_visible_1c_window` означает, что в доступном сеансе не найдено окно 1С;
это не доказывает отсутствие поддержки автоматизации.
`inspection_complete` означает завершение сбора дерева, а не подтверждение
пригодности всех полей. Ошибки и ограничения обхода указаны в отчёте.

Следующий этап — оценить дерево на форме документа и выбрать исполнитель:
Windows UI Automation либо отдельный адаптер тестирования платформы 1С.
Совместимость второго варианта пока не проверена. Внутренние имена из
старого `.feature` нельзя считать идентификаторами Windows UI Automation.

После выбора исполнителя нужны проверяемые шаги с ожидаемым результатом,
журнал событий и координат для монтажа, запись экрана, озвучка и аннотации.
Эти части пока не реализованы. Пробный и чистовой проходы должны начинаться
с одного состояния учебной копии базы.

## Проверка фокуса без изменения документа

Пользователь подтвердил, что работает с учебной копией.
Откройте один документ поступления и запустите двойным щелчком
`Проверить управление 1С.cmd`. Скрипт ищет одно доступное поле
«Комментарий:», читает его значение, ставит фокус и проверяет, что
фокус подтверждён, а значение осталось прежним. Текст не вводится,
кнопки записи и проведения не нажимаются. При нескольких подходящих
полях скрипт останавливается. Результат: `artifacts/focus-test.json`.
Не вводите текст в 1С во время короткой проверки.

## Окно приложения

Запустите `Открыть студию 1С.cmd` двойным щелчком. Откроется окно
с двумя кнопками: проверка доступности интерфейса и проверка фокуса.
Каждая проверка выполняется в отдельном процессе в вашем сеансе Windows;
таймаут 45 секунд. Результат показан простым текстом и сохранён в artifacts.
Доступность окон из сеанса разработки может отличаться от доступности
в вашем интерактивном сеансе. Приложение пока выполняет только диагностику.

## Демонстрационная запись

Кнопка «3. Записать демонстрацию» переключает фокус между полями «Номер»,
«Контрагент» и «Комментарий» существующего документа. Перед записью все
три поля должны быть найдены однозначно. Значения проверяются до и после.
Студия сворачивается на время записи и возвращается после завершения.
Не переключайте окна и не вводите данные во время прохода.

Сохраняются видео `artifacts/demo-<дата-время>.avi` и журнал
`artifacts/demo-result.json`. Записывается весь монитор с выбранным полем,
поэтому уберите с него посторонние окна. Рамки и пояснения добавляются
непосредственно в кадры. Формат Motion JPEG AVI, 6 кадров/секунду,
12 секунд видео без аудио; при медленном захвате реальный проход длиннее.
При ошибке частичный видеофайл не считается успешным результатом.
Это демонстрация фокуса, а не заполнение документа или декларации.
