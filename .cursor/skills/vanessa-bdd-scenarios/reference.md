# Чеклист перед запуском сценария Vanessa

Ориентир: обработка **Vanessa Automation single 1.2.043.1** (при смене версии перепроверьте шаги в «Известные шаги»).

## Режим работы агента

1. **Режим «тема + пример» (видеоинструкция с нуля):** пользователь описывает тему и цифры словами. В ответе **по порядку:** (а) **базовый сценарий** словами + таблица данных, (б) **сверка** с логикой БП 3.0 (`docs/1c-buh30-3.0.194.23-agent-reference.md`) и с типовыми шагами Vanessa, (в) **готовый `.feature`** для вставки. По просьбе «только базовый» — только (а). **К 1С агент не подключается.**
2. **Режим «уже есть код»:** пользователь вставляет `.feature` или запись шагов — агент **переписывает под библиотеку** Vanessa и убирает типичные ошибки.
3. Цель — **минимум ручных правок**; имена полей при необходимости уточнять в «Известные шаги» и одной записью в 1С.

## Файл `.feature`

- [ ] Первая строка: `#language: ru`
- [ ] Для `@tree` везде **табы**, не смешивать с пробелами
- [ ] Теги `@tree`, при видео — `@Video`
- [ ] Нет лишних `Тогда открылось окно` (ожидаемое окно = реально активное после шага)

## Сценарий

- [ ] Контекст: запуск TestClient и закрытие окон — как в шаблоне
- [ ] Кнопки списка поступлений: не полагаться на общую «Создать», если нужен **`СоздатьПоступлениеТовары`**
- [ ] Таблицы с примерами: текст ячеек **скопирован из 1С** (кавычки, пробелы)
- [ ] Гиперссылки и «Цены и валюта»: не использовать `И в меню формы я выбираю`, если элемент не верхнее меню — шаг из «Известные шаги»
- [ ] Закрытие: по возможности `И Я закрываю текущее окно` вместо жёсткого номера документа

## Vanessa (программа)

- [ ] В «Известные шаги» есть используемые формулировки (версия обработки совпадает)
- [ ] Для видео: включены нужные опции автоинструкции, каталоги видео/временных файлов заданы
- [ ] Ошибка «создание скриншота» / IrfanView: настроить команду скриншота по FAQ или не опираться на скриншоты для MP4

## После правок

- [ ] Один пробный прогон до первой ошибки — при необходимости поправить одну строку и снова запустить
