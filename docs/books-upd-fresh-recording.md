# Свежая запись: поступление книг по УПД

Это новая запись экрана открытой учебной базы. Ролик из папки `artifacts/books-creation` сюда не подставляется. Vanessa Automation не используется.

На компьютере с Linux и в облаке Cursor живая 1С и сервис озвучки не запускаются. Команды ниже выполняются на вашем Windows, когда учебная база уже открыта.

## Что программа делает и чего не делает

- Создаёт **новый** документ поступления и может его провести.
- Номер входящего УПД каждый раз новый. `УЧ-КНИГИ-001` и `УЧ-КНИГИ-002` повторно не записываются.
- Номера, которые уже видны на экране, только **читаются**. Старый документ из-за этого не открывается.
- Базу не восстанавливает, файл выгрузки базы не подменяет, документы не удаляет и не исправляет.
- Каждая короткая фраза звучит, когда курсор уже на нужном поле. Рамка берётся из окна в этот момент.
- Если подпись не найдена, их несколько или сумма не сходится, запись останавливается. Чужую рамку программа не рисует.
- Голос — Лили (`pFZP5JQG7iQjIQuC4Bku`), модель `eleven_multilingual_v2`. В субтитрах обычные слова, без знаков ударения. Ударение в «дебет» и «кредит» попадает только в речь.
- Уже озвученные фразы берутся из `artifacts\tts-cache`. Повторный запуск с тем же текстом новый запрос не делает.
- Каждый запуск без `--out` кладёт результат в новую папку `artifacts\books-upd\дата-время`.

Перед записью оставьте одно окно 1С на начальной странице. Лишние окна закройте сами. Клавишу Esc программа сама не нажимает, чтобы не закрыть чужой документ.

## Шаг 1. Один раз поставить программы

В PowerShell, в папке проекта:

```powershell
py -3 -m pip install -r requirements.txt
ffmpeg -version
```

Ключ ElevenLabs — только в файле `.env` на вашем компьютере (кнопка `Подключить ElevenLabs.cmd`). В команду ключ не вставляйте. В `.env` не меняйте модель: нужна `ELEVENLABS_MODEL_ID=eleven_multilingual_v2`. Если строки нет, программа сама берёт эту модель.

## Шаг 2. Пробный прогон

Откройте учебную базу. Затем:

```powershell
py -3 -m pipeline live --lesson "lessons\books-upd.yaml" --dry-run --confirm-training-copy
```

Тот же запуск двойным щелчком: `Пробный прогон поступления книг.cmd`.

Пробный прогон ничего не нажимает и видео не пишет. Отчёт лежит в новой папке `artifacts\books-upd\…\preflight.json`.

- Код 0: вкладка «Покупки» найдена. Полей будущего документа на начальной странице ещё нет — это нормально, они перечислены как «на этом экране пока нет».
- Код 2: вкладки «Покупки» нет, подпись нашлась несколько раз или сумма на уже открытой форме не сходится. Запись не начинайте. Озвучка при этом не запрашивается.
- Код 1: окно 1С не найдено или прогон остановился.

Раздел «Покупки» в Такси — вкладка (`ControlType.TabItem`), не пункт меню. Если отчёт пишет, что подпись есть, но тип другой, в урок нужно вписать этот тип. Уже скачанные фразы в `artifacts\tts-cache` программа не стирает.

## Шаг 3. Запись

Когда пробный прогон вас устроил и открыта именно учебная копия:

```powershell
py -3 -m pipeline live --lesson "lessons\books-upd.yaml" --confirm-training-copy --tts elevenlabs --voice pFZP5JQG7iQjIQuC4Bku
```

Либо `Записать поступление книг.cmd` и ответ `YES`.

Папку `--out` можно не указывать: у каждого запуска своя. В ней будут:

| Файл | Зачем |
| --- | --- |
| `lesson.mp4` | Ролик. Картинка и фраза совпадают по времени |
| `subtitles.srt` | Субтитры обычным текстом |
| `raw-screen.mp4` | Непрерывная запись окна, без перестановки кадров |
| `audit.json` | Что нажали, какой номер выбрали, какие рамки сняли |
| `coverage.json` | Какая фраза какой элемент показала |
| `timing-report.json` | Время показа и время фразы |
| `errors.json` | Пустой, если проход дошёл до конца. Иначе причина остановки |
| `preflight.json` | Только у пробного прогона |

`--tts auto` для этого урока отключён: запасной голос не подменяет Лили.

Если шаг не найден, в `errors.json` будет его имя. Исправьте подпись на форме или в `lessons\books-upd.yaml` и запустите снова. Новый номер будет другим. Получившийся незавершённый документ программа не удаляет — уберите его сами, если он больше не нужен.

Старый сборщик `tools\Build-BooksCreation.ps1` без ключа `-Legacy` теперь останавливается и новый ролик не выдаёт.
