### Расширения конфигурации (учитывать при сценариях)

Подключены расширения (имена как в конфигураторе / списке расширений):

- **EF_3799**
- **EF_202**
- **EF_188**

Префикс **EF_** у типовых поставок 1С часто соответствует **исправлениям (патчам)** или отдельным модулям из линейки обновлений. Точное назначение каждого расширения смотреть в базе: **Администрирование** (или **Главное** → **Интернет-поддержка** / настройки) → **Печатные формы, отчёты и обработки** / **Расширения** — описание у каждой строки. В сценариях Vanessa не подставлять лишние шаги «наугад» под расширения без проверки в интерфейсе.

## Важно: что нельзя считать «полной копией документации»

1. **Полная документация** по конфигурации размещена на портале **1С:ИТС** ([its.1c.ru](https://its.1c.ru)) и распространяется на условиях подписки. **Скачивать и хранить в репозитории полный снимок ИТС недопустимо** (авторское право, лицензия).
2. Страница [v8.1c.ru/buhv8](http://v8.1c.ru/buhv8/) — **маркетинг и обзор продукта**, не пошаговая методичка по всем документам.
3. Для агента в Cursor достаточно **этого файла + ссылок + выжимок**, которые пользователь сам добавляет из своей базы (скриншоты путей, подписи полей).

**Вывод для агента:** опираться на этот файл, на **запись шагов Vanessa** и на **встроенную справку 1С** (F1) в той же версии базы. Не выдумывать внутренние имена полей, если их нет во вводных.

## Как пользователю дополнить материал для агента (рекомендуется)

Чтобы снизить риск ошибок в сценариях **без доступа к ИТС из Cursor**:

1. В1С открыть нужный документ / список → **F1** (встроенная справка по форме).
2. Сохранить или скопировать **путь в интерфейсе** и **подписи полей**, которые видны на экране.
3. Добавить в проект файл, например `docs/bp30-moi-dokumenty.md` (один файл на типовую операцию: поступление, ОС, зарплата и т.д.).

Агент тогда сопоставляет это с шагами Vanessa, а не с общими догадками.
